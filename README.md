# Marina Martin

Most of what I build gets data out of systems that were never meant to give it up, PDFs, career pages, a message thread with no API, and turns it into something a person can act on. CIS at Baruch College, May 2027, in New York.

**[statement-agent](https://github.com/marinasofia/statement-agent)** · Turns a folder of PDF bank statements into one Excel workbook, split by statement month and deduplicated, for the case where statements arrive from different banks in different layouts and someone is otherwise retyping them. Claude does the extraction, Pydantic checks the result, and a failed check gets exactly one corrective reprompt before the file is flagged for a human instead of being silently accepted. New client layouts are a YAML file rather than a code change. Uploads are checked for path traversal, document text is never concatenated into the system prompt, and invisible Unicode is stripped before anything is parsed.

**[hermes](https://github.com/marinasofia/hermes)** · A job matching agent that reads the career pages of 23 fintech and AI companies plus the community internship boards, and tells me which roles are actually worth an application. The engineering that matters is the filtering: 4,403 postings on those boards come down to 260 Claude calls per run through a regex and location pre-filter, a dedupe on the posting hash, and deterministic exclusion rules, which is what keeps a run at about $0.025 instead of $2. Every response is schema validated with one corrective reprompt and then logged rather than retried forever. 50 tests against a mocked client, and a [live dashboard](https://marinasofia.github.io/hermes/) showing the pipeline stats and scored roles by sector. A Chrome extension for one click scoring and a resume editor run against the same pipeline in the private half of the repo.

**ReKindle** · A networking app that remembers people for you. It is live, with real accounts, cloud sync, and Google Calendar pulled in over OAuth so it can prep you before an event and remind you to follow up after. Most of the engineering is integration into systems that do not offer an API: a Chrome extension reads your LinkedIn conversations off the page, a macOS menu bar companion falls back to OCR where a channel exposes nothing at all, and both talk to the core app over a versioned schema so a sensor can change without breaking the product. It also runs entirely on device with nothing configured, which is a supported mode rather than a degraded one. The model work is benchmarked separately before it goes near the app: a cadence-only model that predicts which relationships are about to go quiet, 0.93 ROC-AUC on 38,069 held out rows of public email network data, and a sentiment model for interpersonal messages that cuts a VADER baseline's neutral-collapse rate from 21.3% to 10.2%. Two later versions of that model beat it on every continuous metric and still did not ship, because they failed a pre-registered gate. Eight repositories, code private.
