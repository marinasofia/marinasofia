## What I'm building

- **[Sourcer](https://github.com/marinasofia/sourcer)**: reads company job boards every morning, drops what cannot fit with explainable rules, and has Claude score the rest against quoted evidence. One run read 48,031 postings and set aside 95% before a single model call.
- **[Knowledge Assistant](https://github.com/marinasofia/knowledge-assistant)**: answers policy questions with the exact approved passage, shows both sides when two policies disagree, and refuses when nothing covers the question. 10 of 10 unanswerable questions refused on a held out eval.
- **[Statement Agent](https://github.com/marinasofia/statement-agent)**: a LangGraph agent that turns PDF bank statements into Excel and trusts a number only when the balances reconcile to the cent.
- **[Bank Churn Model](https://github.com/marinasofia/bank-churn-model)**: a churn model that sizes the outreach list to a retention team's capacity and audits who it leaves out, by gender and income.

Also: [sakura-terminal](https://github.com/marinasofia/sakura-terminal), a small tool for watching several Claude Code agents at once.
